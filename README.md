# 🧭 Navigation Menu

A simple navigation menu created using HTML and CSS. This project provides an easy way to navigate between different webpages such as Home, About Us, Gallery, Project, and Achievement using hyperlinks.

## 📌 Features

- Simple Navigation Bar
- Gradient Background
- Centered Menu Layout
- Styled Navigation Links
- Clean and Modern Design
- Easy Page Navigation

## 🛠️ Technologies Used

- HTML5
- CSS3

## 📂 Project Structure

```
Navigation-Menu/
│── index.html
│── about us.html
│── Gallery.html
│── project.html
│── Achivment.html
│── README.md
```

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in any web browser.
4. Click the navigation links to visit different pages.

## 📚 Concepts Used

- HTML Lists (`<ol>` & `<li>`)
- Hyperlinks (`<a>`)
- CSS Flexbox
- Linear Gradient Background
- Border Radius
- Text Styling

## 📸 Output

The webpage displays:
- Home
- About Us
- Gallery
- Project
- Achievement

All menu items are arranged in a centered navigation bar with a clean and attractive design.
